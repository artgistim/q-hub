# Q Hub｜Qualtrics EX 學習地圖

Tim Cho 的新人關懷學習與實作教材。以三份 Engagement 練習新人、主管與夥伴回饋。

網站：https://artgistim.github.io/q-hub/

## 從這裡開始

- `index.html`：30 堂主線＋6 堂支線、37 題中文題庫、分類來源與完整教材下載。
- `lab.html`：16 個實作單元、三角色圖表、12 任務 POC 與 432 任務規劃的模擬對照。
- `resources.html`：49 筆進階資源、技術對照與主管評多人方案，支援搜尋及篩選。
- `materials.js`：單檔下載資料，包含 CSV、Word、題庫、Markdown、SQL 與圖片。
- `materials.zip`：完整教材包，含原始格式、檔案清單與 SHA-256。

下載整個儲存庫後，直接開啟 `index.html` 即可離線閱讀。請保留五個主要檔案在同一資料夾。外部文章與影片仍需連線；未鏡像來源全文。關閉 JavaScript 時仍可閱讀靜態課程及下載 ZIP，互動圖表與篩選需要 JavaScript。

CSV 保留 UTF-8 BOM、欄位與原始用途。四位新人、信箱、回答與長期規劃均為虛構；不是實際平台回收，也不會寄出任何訊息。官方圖片為介面參考；另有 32 張圖片保留在官方文章 Word 指引。實驗室進度只存於本機瀏覽器，主學習地圖不設測驗、評分或打卡。

來源內容查核：2026-11-07／08。發布整理：2026-11-09。產品權限、功能與正式自動化仍需以公司帳號驗收。

## 發布與維護

本儲存庫是獨立的純靜態發布目錄。GitHub Pages 使用 `main` 分支的 `/ (root)`，`.nojekyll` 停用 Jekyll 處理。無需 npm、Python 後端或資料庫。

本機母專案以 `python3 -B py_code/build_github_io.py` 重建發布目錄，再以 `python3 -B py_code/check_github_io.py` 檢查。維護來源為母專案既有 HTML、教材與資料；請勿直接修改產生檔後又重建。

教材只採用明確允許的檔案清單，不包含個人帳號檔、環境設定與憑證。若 CSV 出現非 example.com 信箱、實際專案 ID 或填寫過的帳號驗收紀錄，重建器會停止，需先準備適合公開的版本。

架構參考 AIHR 文章學習發布版：獨立發布、靜態閱讀、內嵌資源、搜尋分類；內容沿用本專案的 Qualtrics 教材。Qualtrics 商標、官方介面與外部文章權利歸原權利人，本站為個人學習整理，非官方認證課程。
